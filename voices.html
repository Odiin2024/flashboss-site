Voices

What it sounds like

Every card in FlashBoss can speak. These are the actual voices — not demo recordings. Each clip below is a real sentence from a real card, read by the exact neural voice, at the exact speed, the game uses for that pack. The speech runs offline, on your own machine: no account, no server, no internet.

It will read anything you give it

Press Ctrl + P anywhere in the game and a pronunciation window opens. Paste in a word, a sentence, a paragraph from something you are reading — it speaks it in the voice you are learning with, and saves it to a file if you want to keep it. It works while a card is on screen, in the menus, in the middle of a boss fight.

Card audio is cached the first time it plays, so a session you have run before speaks instantly and works with no connection at all.
